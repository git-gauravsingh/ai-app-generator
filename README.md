# AI App Generator

## Overview

AI App Generator is a dynamic low-code application builder that generates user interfaces from JSON configuration. Users can edit JSON in real time and instantly preview generated UI components.

## Features

* Dynamic JSON Rendering
* Live Preview
* Import JSON Configuration
* Export JSON Configuration
* Undo / Redo Support
* Resizable Panels
* Theme Toggle
* Error Handling
* Empty State Handling
* Unknown Component Handling
* Dynamic Component Registry

## Supported Components

* Card
* Button
* Input
* Table
* Form

## Tech Stack

* Next.js 16
* TypeScript
* Zustand
* Tailwind CSS
* React
